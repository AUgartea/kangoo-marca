# Kangoo · Marca y narrativa

Repositorio de marca de Kangoo para el equipo de marketing. Reúne en un solo lugar qué es Kangoo, cómo habla, qué se puede prometer, y su identidad visual, para que todo lo que se haga en marketing calce con el producto.

## Cómo usarlo con una IA

- **Claude (Cowork o Claude Code):** abre o conecta la carpeta del repositorio. Claude lee `CLAUDE.md`, que apunta a `AGENTS.md`.
- **ChatGPT u otra herramienta:** conecta el repositorio o adjunta `AGENTS.md` y los archivos que necesites, y pídele que lo lea antes de empezar.

En ambos casos, pide las piezas normalmente ("un post de Instagram para cuidadoras", "el texto de un correo de bienvenida"): las reglas de `AGENTS.md` se encargan de la coherencia.

## Estructura

```
AGENTS.md            instrucciones para la IA (léelo tú también)
CLAUDE.md            apunta a AGENTS.md
narrativa/           qué es Kangoo, tono de voz, qué se puede decir
marca/               identidad visual, ilustraciones y assets
oferta/              planes y precios
referentes/          análisis de referentes
```
